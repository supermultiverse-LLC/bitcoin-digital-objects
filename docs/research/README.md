# Research

This directory contains **informative research notes**.

A research note explores a question relevant to the Bitcoin Digital Objects
architecture — compatibility studies, design explorations, comparative
analyses — before any standards-track work exists for it.

Research notes:

- are informative and experimental;
- define no conformance and carry no normative effect;
- do not modify the BDO architecture, BDO-01, STAS-01, or any RFC;
- may propose directions, which become real only through the governance
  process (issue → RFC → acceptance).
